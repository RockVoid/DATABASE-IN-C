# MINI DATABASE IN C

This is a project to create database with some simple commands in C, using the main functionalities of a DB architeture.

## How can I run this project?

1. First:

    `git clone https://github.com/RockVoid/DATABASE-IN-C.git` 

2. Then you can try to run the project on command line via GCC:

    `gcc main.c -o main.exe
    `

3. Then:

    `./main.exe`


### WARNING

If you prefer use one IDE to run this program, be sure you have GCC configured inside your IDE to compile and run C programs. Some libs may not working on some systems or could be deprecated on newer windows versions.

Enjoy!
